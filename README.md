# Wifey for iPhone — prototype v0.1

This is a mobile-first, installable web-app prototype designed for iPhone.

## Run locally
Serve this folder over HTTPS (or localhost) with any static web server. For example:
```bash
python3 -m http.server 8000
```
Then open the local URL in a browser.

## Install on iPhone
1. Host the folder on an HTTPS website.
2. Open the website in Safari on iPhone.
3. Tap Share → Add to Home Screen.

## Included
- Wifey-branded mobile interface
- Chat UI with a small local demo-response engine
- Text-to-speech using the browser's speech synthesis
- Optional speech-to-text when supported by the browser
- English/Taglish personality copy
- PWA manifest and service worker

## Important limitations
This is a front-end prototype, not yet a production AI companion. Chat replies are local demo responses, not generated by an AI model. Voice recognition support varies by iOS/browser version. The voice is the device/browser voice, not a custom cloned voice. No cloud memory, authentication, database, live video, or 3D avatar is connected.
